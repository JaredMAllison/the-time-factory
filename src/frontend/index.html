HOW IT WORKS
🎈BalloonOne event or task
➖BeltThe timeline — drag left/right or use ← → keys to scroll
↕String lengthTime of day — short string = early, long = late, resting on belt = all-day
🎨ColorCategory (configured in config.json)
💓Pulse speedUrgency — still = Low, slow = Normal, fast = High, rapid = Critical
🏷TagClick to open event details
◀ ▶Preview zonesDimmed, smaller balloons on either side = adjacent days
✔Pop ItMarks an event complete — balloon becomes a popped remnant

Navigate with ← → arrow keys, click-drag the belt, or use the ⊙ Warp button to jump to any date.
